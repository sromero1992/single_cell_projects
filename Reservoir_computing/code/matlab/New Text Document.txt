**Core functions** (`scReservoir/`):

| File | Description |
|---|---|
| `scReservoir_init.m` | Initialize sparse or dense random reservoir (W_res, W_in) with spectral radius normalization |
| `scReservoir_run.m` | Drive reservoir with gene expression via leaky integrator, return state matrix H |
| `scReservoir_preprocess.m` | Library-size normalization, log1p, HVG selection (Seurat-style dispersion binning) |
| `scReservoir_GRN.m` | GRN inference in **static**, **causal** (lagged), or **velocity** (dx/dt) mode, with ensemble averaging |
| `scReservoir_graphGRN.m` | kNN cell graph propagation (scGraphResNet) for branching trajectories |
| `scReservoir_scalable.m` | Atlas-scale: sparse reservoir + randomized SVD — ~100× speedup for >50k cells |
| `scReservoir_landscape.m` | Full pipeline: latent dynamics → attractor detection → Waddington landscape → fate probabilities → GRN |
| `scReservoir_plot_GRN.m` | Heatmap + digraph network visualization |
| `scReservoir_plot_landscape.m` | 3D energy landscape, 2D potential contours, fate probability maps |

**Examples** (`examples/`): three standalone `.m` scripts covering basic GRN → graph+velocity → full landscape, each runnable on synthetic data with placeholders to swap in real `.mat` files.
