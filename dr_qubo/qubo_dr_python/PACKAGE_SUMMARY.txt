================================================================================
KEY ALGORITHM FEATURES
================================================================================

1. BIOLOGICAL CONTEXT
   - Identifies K-gene subnetwork with maximum differential co-expression
   - Within a specified biological pathway (KEGG or GO)
   - Between two conditions (e.g., KO vs WT)

2. PATHWAY INTEGRATION (NEW)
   ✓ Automatic KEGG pathway gene fetching
   ✓ Automatic GO Biological Process gene fetching
   ✓ Support for human, mouse, fly, worm, rat genomes
   ✓ Two GO data sources: gseapy library or QuickGO REST API

3. DIFFERENTIAL CO-EXPRESSION
   ✓ Gram matrix formulation (cosine similarity)
   ✓ Condition-specific similarity matrices
   ✓ Xdiff = Xwt_coexpr - Xko_coexpr

4. GRAPH CONSTRUCTION
   ✓ SVD dimensionality reduction
   ✓ K-nearest neighbor search (Euclidean)
   ✓ Mutual nearest neighbor (MNN) symmetrization

5. QUBO OPTIMIZATION
   ✓ Matrix assembly with cardinality constraint
   ✓ Penalty-based enforcement of subnetwork size K
   ✓ Pathway network penalties for coherence

6. SOLVING
   ✓ D-Wave simulated annealing (if dimod installed)
   ✓ NumPy fallback simulated annealing (no dependencies)
   ✓ Configurable temperature schedule and iterations

7. VISUALIZATION
   ✓ Divergent colormaps for differential matrices
   ✓ Force-directed network layouts
   ✓ Condition-specific edge coloring
   ✓ Gene-level importance scores

EXAMPLE USAGE
================================================================================

Python API:
   from qubo_dr import run_pipeline
   
   results = run_pipeline(
       X=count_matrix,              # genes × cells
       g=gene_names,                # list of str
       batch_id=condition_labels,   # array of str
       source='kegg',
       pathway_id='04310',          # Wnt signaling
       organism='hsa',
       K=30,                        # target subnetwork size
   )

Command Line:
   python run_pipeline.py \
       --data counts.h5ad \
       --pathway-source kegg \
       --pathway-id 04310 \
       --K 30 \
       --num-reads 2000

================================================================================
OUTPUT FILES
================================================================================

1. qubo_genes_solution.txt
   - Selected gene names (one per line)
   - Comment headers with metadata

2. Figures (if plotit=True):
   - figure_0: 3-panel condition comparison (KO, WT, Differential)
   - figure_1: Subnetwork co-expression heatmap
   - figure_2: Gene network graph (force-directed)

3. Python Results Dictionary:
   {
     'sub_g_net': [selected genes],
     'sub_Q_net': (K×K) co-expr matrix,
     'sub_Qv': (K,) node importance vector,
     'selected_idx': (n_genes,) bool array,
     'G_graph': networkx.Graph,
     'Xdiff': (n_pathway, n_pathway) differential matrix,
     'Q1': (n_pathway, n_pathway) unpenalized QUBO,
     'Q': (n_pathway, n_pathway) penalized QUBO,
     'gene_names_subset': [pathway genes],
     'best_energy': float,
     'figures': [(fig, ax), ...],
   }
