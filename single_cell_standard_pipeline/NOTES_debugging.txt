1. CytoTRACE2 — exact working call
────────────────────────────────────────────────────────────────────────────────

KEY POINTS:
  - `verbose` is NOT a valid argument (removed; caused "unused argument" error)
  - `parallelize_smoothing = FALSE` required on Windows (avoids socket cluster issues)
  - `parallelize_models = FALSE` safe default; avoids parallel backend issues
  - Input MUST be converted to dense data.frame first:
        if (!is.data.frame(ct2_input))
            ct2_input <- as.data.frame(as.matrix(ct2_input))
  - Score column is named "CytoTRACE2_Score" in return data.frame (rows = cells)
  - CytoTRACE2 is PURE R — does NOT need Python/torch/reticulate

2. CytoTRACE2 — scoping bug inside tryCatch
────────────────────────────────────────────────────────────────────────────────
RULE: inside a tryCatch({ EXPRESSION }, error = handler) block:
  - The EXPRESSION evaluates in the CALLING environment → use <- (single arrow)
  - The ERROR HANDLER is a function → use <<- to write back to calling env

WRONG (breaks with "object 'results' not found"):
    tryCatch({
        results[["CytoTRACE2"]] <<- ct2_scores   # <<- goes ABOVE calling env!
    }, error = ...)

CORRECT:
    tryCatch({
        results[["CytoTRACE2"]] <- ct2_scores    # <- assigns IN calling env
    }, error = function(e) {
        results[["CytoTRACE2"]] <<- rep(NA, n)   # <<- needed here (inside fn)
    })

3. CytoTRACE2 — so_ann optional assignment must not crash main tryCatch
────────────────────────────────────────────────────────────────────────────────
PROBLEM: `so_ann$CytoTRACE2 <<- ...` inside the main tryCatch body crashed
when so_ann didn't exist, causing the error handler to overwrite good scores
with NA. Fix: store scores first, then guard so_ann in its OWN tryCatch:

    results[["CytoTRACE2"]] <- ct2_scores        # store first — safe
    cat(sprintf("  Done. Score range: [%.3f, %.3f]\n", ...))
    tryCatch(                                     # optional, non-fatal
        if (exists("so_ann", envir = .GlobalEnv))
            get("so_ann", envir = .GlobalEnv)$CytoTRACE2 <<-
                ct2_scores[colnames(so_ann)],
        error = function(e2) invisible(NULL))

4. CellRank — use PseudotimeKernel, NOT CytoTRACEKernel
────────────────────────────────────────────────────────────────────────────────
PROBLEM: CytoTRACEKernel(adata, cytotrace_key=...) requires compute_cytotrace()
to be called first (sets internal state); skipping it raises:
    "Compute pseudotime first."
Since we inject EXTERNAL scores, use PseudotimeKernel instead:

    from cellrank.kernels import PseudotimeKernel, ConnectivityKernel

    ck  = ConnectivityKernel(adata).compute_transition_matrix()
    score = adata.obs[pk].astype(float) * float(sign)
    score = score.fillna(score.median())          # fill NA cells with median!
    smin, smax = score.min(), score.max()
    if smax > smin:
        score = (score - smin) / (smax - smin)   # normalise [0,1]
    adata.obs['_pt'] = score
    ptk = PseudotimeKernel(adata, time_key='_pt').compute_transition_matrix(
        threshold_scheme='soft', nu=0.5)
    T   = (0.8 * ptk + 0.2 * ck).transition_matrix.toarray()
    V   = T @ adata.obsm['X_umap'] - adata.obsm['X_umap']

KEY POINTS:
  - fillna(median) is REQUIRED: methods like scDVEP_H_top10 have NA for cells
    outside the scored threshold; PseudotimeKernel rejects any NaN
  - Normalise to [0,1] so threshold_scheme='soft' is consistent across methods
  - CytoTRACEKernel is only for its own built-in CytoTRACE computation
